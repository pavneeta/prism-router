01 · How it works

Benchmarks set the floor. Cost picks the model.

Prism decides which model runs; LiteLLM calls the provider. Every turn is classified, filtered by an intelligence floor from public scores, then routed to the cheapest eligible option — with session stickiness so prompt caches stay warm.

  1. 01

    Classify the turn

    Map the request to a task type — coding, tools, reasoning, chat — so routing matches the work, not a default model habit.

  2. 02

    Clear the intelligence floor

    Only models that pass benchmark-backed accuracy thresholds for that task stay eligible. Cheaper never means under-provisioned.

  3. 03

    Minimize effective cost

    Among eligible models — often open-source / mid-tier — pick the lowest effective $, including cache-aware pricing and session affinity.

Seeded from DeepSWE, SWE-bench, Terminal-Bench, Artificial Analysis, and Arena. Provenance →
