01 · The point

Pay for the job, not the brand.

Teams either burn frontier models on every turn, or go too cheap and lose the task. Prism Router is the middle path: spend less per completed task while the hard work still clears the bar.

  • Cheaper completions

    Route simple turns to efficient models. Reserve expensive capacity for work that actually needs it.

  • No silent under-provisioning

    Public benchmarks set an intelligence floor per task type. Cost never wins by failing the job.

  • Caches stay warm

    Multi-turn sessions stick when stickiness saves money — so you keep prompt-cache wins instead of thrashing models mid-agent.

02 · Built for

Agent harness owners.

Drop Prism Router in front of your providers. OpenCode, Hermes, and any OpenAI- or Anthropic-shaped client keep their workflow — keys stay on the gateway.

Point the harness at auto. Prism picks the model. You keep the outcome metric that matters: $/task completion.

Mechanism, benchmarks, and API details live in docs — this page is the why.
